Reed cricket scoreboard simulator

A browser copy of the cricket drawing code in src/main.cpp, on the same 32 x 8 grid. Use it to preview pages and animations without the board. It is a hand port, so if you change the firmware animations, change them here too.

Score format, same as the firmware's q command: balls bowled this over (0 to 6, or - to hide the over row), then pages separated by |.
